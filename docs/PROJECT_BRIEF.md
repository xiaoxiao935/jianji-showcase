# 项目背景与设计取舍

## 从日常任务出发

简记·记账簿面向学生和上班族的日常收支场景。设计围绕三个问题展开：一笔钱怎么方便地记下来，重复发生的收支如何整理，以及记录之后如何看懂自己的开销。

因此，项目以“记录 → 整理 → 回顾”为主线，让账单、分类、速记、预算和统计各自承担清楚的任务。

## 1. 先决定信息放在哪里

首页优先呈现收支概览、账单与主要入口；详细趋势和分类分析进入统计页面查看。

这项选择将高频的记录、查账任务与进一步分析分层安排。首页保留明确重点，统计页面则为深入回顾提供空间。

## 2. 让重复场景可以复用

午餐、通勤等收支会反复出现。速记模板复用常用分类和金额，同时保留调整金额的空间。

设计上兼顾两类使用情况：固定金额直接复用，不固定金额沿用分类再填写。模板服务于重复操作，也保留每次记录的灵活性。

## 3. 让分类适应使用习惯

分类支持排序、隐藏和自定义。常用类别前置，不常用类别隐藏，自定义类别补充个人记录方式。

记账与管理入口沿用同一套分类设置，避免不同入口出现各自独立的分类安排。设计重点是保持使用习惯的连续性。

## 4. 把记录和管理连接起来

账单既是首页的回顾内容，也是预算进度和统计汇总的依据。总预算用于查看整体支出，分类预算用于查看具体类别，统计则提供趋势和分布视角。

预算提醒同时提供关闭和查看预算的选择：既给出进一步管理的入口，也允许继续原来的操作。提醒承担引导作用，用户保留决定权。

## 5. 用统一规则建立视觉体验

米白背景、青绿主色和浅色分类图标构成整体视觉。文字层级、间距、圆角与页头对齐采用统一规则，让页面之间保持连贯。

视觉设计服务于信息阅读：金额、分类、说明与操作区具有明确层级，装饰保持克制，关键内容更容易被识别。

## 6. 将设计落实到数据和反馈

| 设计关注点 | 实现中对应的考虑 |
|---|---|
| 金额表达清楚 | 关注计算精度，以及账单、预算与统计的数值一致性 |
| 修改有反馈 | 关注账单变更后相关页面的刷新与汇总更新 |
| 切换有连续性 | 关注统计切换、异步绘制与失败后的重试反馈 |
| 操作有选择 | 提醒提供下一步入口，同时保留返回或关闭路径 |
