# 网页试用路线

**[打开简记·记账簿](https://jianji1602-jianji-showcase-d7fwl86y2a46e651.webapps.tcloudbase.com/)**

面向第一次查看项目的访客，无需下载源码或安装开发工具。下面是建议观察的路径，不是对网页全部交互已通过验收的承诺。

| 顺序 | 可以尝试 | 重点观察 |
|---|---|---|
| 1 | 打开首页 | 收支概览、账单信息和主要入口是否清楚 |
| 2 | 尝试记录一笔虚构支出 | 分类、金额和备注的录入组织方式 |
| 3 | 返回首页查看账单 | 记录是否便于找到和回顾 |
| 4 | 浏览预算与统计 | 记录如何转化为预算进度和收支回顾 |
| 5 | 浏览速记与分类管理 | 常用收支和分类如何适应重复使用 |

请使用虚构金额和备注，不输入真实账本或个人资料。不必尝试绑定手机号、账号注销或内置拍照识别等尚未开放的能力。

网页试用不等于正式小程序已经上线。遇到问题可通过展示仓库的 [Issues](https://github.com/xiaoxiao935/jianji-showcase/issues) 描述页面、步骤、预期与实际结果；不要附真实账单、登录信息或私人联系资料。
