# 试用常见问题

## 怎样体验项目？

打开 [网页试用](https://jianji1602-jianji-showcase-d7fwl86y2a46e651.webapps.tcloudbase.com/)，按 [试用路线](TRY_IT.md) 浏览。无需下载代码或自行部署。

## 网页和截图为什么可能不同？

图片来自独立的模拟器运行环境，网页是单独的试用版本。两者不代表同一发布状态；具体可用功能以对应版本为准。

## 可以录入真实账单吗？

当前入口用于项目试用，建议只输入虚构金额和备注，不提交真实账本、个人头像、手机号或其他私人资料。

## 为什么有些功能不能使用？

手机号绑定、账号注销删除、内置拍照识别和微信定时通知尚未开放。语音输入依赖手机输入法，不代表已接入内置识别服务。

## 手机和电脑都能打开吗？

这是网页试用入口，可用浏览器打开，页面以移动端体验为设计重点。没有完成全部设备兼容性验收，遇到显示异常可记录设备、浏览器和页面反馈。

## 打不开网页或操作异常怎么办？

可以先刷新页面、检查网络或换一个浏览器尝试。问题持续时，使用 [问题反馈](https://github.com/xiaoxiao935/jianji-showcase/issues/new?template=problem.md)，说明页面、步骤、预期和实际结果。不要为了排错清空真实数据或上传私人备份。

## 仓库为什么没有业务源码？

本仓库作为项目作品集，展示产品、设计取舍和试用入口；不提供业务源码和自建部署教程。
