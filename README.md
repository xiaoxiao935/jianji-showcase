# 简记·记账簿

一个轻量、简洁的个人记账项目，集收支记录、预算管理、分类整理与统计回顾于一体。

本页用于展示项目成果、设计思路和实现概况。

简记·记账簿围绕日常收支中的三个任务展开：快速记录、按习惯整理，以及清楚地回顾开销。项目将账单、分类、常用收支模板、预算与统计组织为一条连贯的使用路径，让记录后的数据继续服务于日常管理。

产品面向学生和上班族，设计重点是移动端的日常使用：常用操作容易找到，重复收支可以复用模板，详细分析按需进入；视觉上使用米白背景与柔和青绿，保持页面层级与操作方式的一致。

## 项目特点

### 1. 围绕日常记账组织信息

首页优先呈现收支、账单与主要入口，详细分析放在统计页面。将高频记录和深入回顾分开安排，让首页保持清楚的使用重点。

### 2. 常用模板服务重复场景

午餐、通勤等常见收支可以保存为速记模板，复用分类与常用金额，也允许在使用时修改。设计重点是减少相同信息的重复填写，而不是要求每次重新录入。

### 3. 分类随个人习惯调整

分类支持排序、隐藏与自定义。常用类别可以前置，不常用类别可以隐藏；记账入口与分类管理使用一致的分类设置，让记录方式更贴近日常习惯。

### 4. 从记录延伸到预算与回顾

账单记录之后，可以通过总预算、分类预算和统计图表继续查看支出。项目关注记录、预算判断和统计汇总之间的一致性，让各页面围绕同一本账展开。

### 5. 统一、克制的移动端视觉

以米白、青绿和浅色分类图标建立视觉识别，统一文字层级、间距、圆角及页头位置。页面保持温和、清晰，不依赖大量装饰突出内容。

### 6. 可直接体验的完整项目呈现

提供网页试用、六张页面图片和操作演示，访客可以从实际使用路径理解产品；设计说明进一步解释功能安排与交互取舍，便于结合体验讨论实现思路。

## 核心功能

| 功能 | 使用场景 |
|---|---|
| 收支记录 | 按分类记录收入、支出、日期与备注，并在账单中回顾 |
| 分类管理 | 调整排序、隐藏类别或添加自定义类别 |
| 速记模板 | 复用常见收支的分类和金额 |
| 预算管理 | 查看总预算、分类预算及支出进度 |
| 统计回顾 | 通过趋势和分类分布查看收支情况 |

## 试用建议

建议按以下顺序体验，并使用虚构金额和备注：

1. 查看首页的收支与账单布局。
2. 尝试记录一笔支出，检查分类、金额和备注的填写方式。
3. 查看预算、统计、分类管理与速记等页面。

网页试用不要求下载源码、安装开发工具或自行配置云环境。详见 [网页试用路线](docs/TRY_IT.md)。

## 设计思路

- **记录更顺手**：围绕金额、分类与备注组织录入，常用收支可通过模板减少重复填写。
- **回顾更清楚**：首页呈现收支与账单，统计与预算承担进一步查看和管理的任务。
- **视觉更统一**：使用米白背景、青绿主色与清晰的文字层级，保持页面之间的布局一致。

更多背景和取舍见 [项目设计说明](docs/PROJECT_BRIEF.md) · [常见问题](docs/FAQ.md)。
